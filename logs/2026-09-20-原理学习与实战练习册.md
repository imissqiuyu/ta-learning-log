## 🧪 今天在 UE 里亲手做的实验

### 练习 1 · 被挡住的像素，GPU 有没有白跑？

```
做法：放 1 个球占满屏幕 → 记 stat gpu → 复制成 20 个完全重叠 → 再记
结果：数字几乎没变
```

**学到**：不透明材质有 **Early-Z** —— 被挡住的像素**根本不做像素着色器**。
屏幕上看到的一个球，GPU 真的只算了一个球。

**核心公式**：
```
一个材质的性能 = 每条像素的代价 × 它真正跑了多少像素
                 ↑ 人人都在优化      ↑ 经常被忽略，但往往是大头
```

### 练习 2 · 让 Early-Z 失效，看看代价

```
做法：材质改成「已遮罩」，mask 值填 0.6，同样 20 个球
结果：Base Pass 明显变高
```

**学到**：Masked 的 shader 里有 `discard`，
**像素要不要丢得先算完 mask 才知道，硬件没法提前剔除。**

> ⚠️ **最反直觉的地方**：mask 值是 0.6（大于剪切值 0.333），
> **其实一个像素都没丢，但代价照样产生了。**

**Masked 的成本不在于它多做了什么，而在于它让 GPU 少做不了什么。**

### 练习 3 · 摸到那条「硬边」

```
做法：Opacity Mask 接一个标量参数，在材质实例里从 0 拖到 1
结果：0 ~ 0.33 球不见；0.33 附近【啪】地一下出现；没有渐变
```

**学到**：**Masked 是二值判断** —— 只有「画」和「不画」，没有中间态。

**默认剪切值是 0.333**（不是 0.5），在细节面板里叫「不透明蒙版剪切值」。

**然后我把边界做成了有形状的**：Opacity Mask 接「纹理坐标」的 U 分量
→ 球缺了三分之一，**边缘是锯齿状的硬边**。

### 练习 4 · 为什么球里面是空的？

**这个练习是我自己「问」出来的** —— 我看到缺口后追问了两个问题：

| 我问的 | 答案 |
|---|---|
| 为什么缺的是背面那一块？ | **纹理坐标（UV）**决定的：U 绕球一圈，接缝在背面，`U < 0.333` 那块正好挨着接缝 |
| 为什么从缺口看进去能看到天空和地板？ | **背面剔除** —— 材质默认单面，背对你的那一半被 GPU 扔掉了 |

**AI 去查了源码给我证据**（`MeshPassProcessor.cpp`）：

```cpp
ERasterizerCullMode FMeshPassProcessor::ComputeMeshCullMode(...)
{
    return bMeshRenderTwoSided ? CM_None : CM_CW;
}
```

| 设置 | 剔除模式 |
|---|---|
| **单面（默认）** | `CM_CW` → 剔除一半的面 |
| **双面** | `CM_None` → 两面都画 |

**缺口处两层都没了：**
```
近处的面（朝向你）  → 被 mask 切掉了
远处的面（背对你）  → 是背面 → 被剔除
                   → 中间什么都没有 → 看到背景
```

**验证方法**：勾上「双面」再往缺口里看 → 就能看到球的内壁了。

> 🔗 **这直接解释了护盾材质为什么必须勾双面** ——
> 不勾的话护盾会穿帮，完全不像"罩住物体的能量罩"。

## ⚠️ 今天卡住的地方（5 个）

### ① 练习 3 里找不到「Opacity Mask」

| | |
|---|---|
| **现象** | 在材质里死活找不到 `Opacity Mask` |
| **根因** | **改混合模式为「已遮罩」之后，必须点「应用」，引脚才会出现** |
| **谁的问题** | **AI** —— 文档只写了"混合模式=已遮罩"，没说要点应用、没说引脚在输出节点上 |

**顺便搞清楚一个容易混的点：**

```
不透明蒙版（Opacity Mask）        ← 输出节点上的【引脚】，接"遮罩图"
不透明蒙版剪切值（Clip Value）     ← 细节面板里的【数值】，默认 0.333
```

### ② 改成 UV 之后「没任何变化」

| | |
|---|---|
| **现象** | 按文档把 Opacity Mask 接到 UV 的 U 分量，球看起来没变化 |
| **真相** | **缺的那块在球背面，我没有转视角** |
| **谁的问题** | **AI** —— 没提醒转视角，也没把"变化在背面"列进排查表 |

> 🎯 **这个坑很有代表性：**
> **「我以为它没工作」和「它真的没工作」是两回事。**

### ③ 练习册里的英文术语看不懂

| | |

## 💡 今天学到什么

### 技术层面

1. **Early-Z**：被挡住的像素不跑像素着色器；`discard` 会让它失效
2. **Masked 是二值判断**，成本在 Early-Z 失效，不在"混合"
3. **默认剪切值是 0.333**
4. **背面剔除**：材质默认单面，GPU 剔除背对你的那一半
5. **什么情况必须开双面**：单片面片（树叶旗帜）、球壳（护盾气泡）、需要看内壁

### 方法论层面

| 学到 | 来源 |
|---|---|
| **读不懂要说出来**，不要硬啃 | 反馈文档太抽象 |
| **「没看到变化」≠「没有变化」** | 缺口在背面 |
| **每一个"没反应"都要先确认观察范围够不够** | 同上 |
| **术语要查证，不能凭印象** | 剪切值 vs 裁剪值 |
