## ❓ 今天我提的问题（都很关键）

### ① 材质实例和材质是什么关系

我之前的困惑：练习 3 里在实例里拖滑杆能用，但更早的时候 `Progress` 在实例里找不到。

**打通后的理解：**

```
母材质   = 程序（要编译）
材质实例 = 配置文件（只改数值，不编译）

好处：
  1. 改参数不用重编译（实时生效）
  2. N 个实例共用一份 shader（省包体 / 编译时间）
  3. 美术碰不到节点图，改不坏
```

**顺带解释了我之前的困惑**：`Progress` 被设成了 Custom Primitive Data，
它的值不再由实例驱动 → **所以从实例的参数表里消失了**。

> 🎯 **同一枚硬币的两面**：实例就是"参数表"，
> 不走"材质参数"这条路的参数（比如 CPD），自然不在表上。


> 💡 **这个「给证据而不是给保证」的做法很重要。**
> 它没有说"你放心我很安全"，而是让我自己去查。

## 💡 今天学到什么

### 技术层面

今天的重点不是新知识点，而是**看清了鸣潮的技术栈**：

| 技术 | 鸣潮的做法 |
|---|---|
| 渲染路径 | **延迟渲染**（UE），基于 PBR 的 NPR |
| 阴影 | **LUT 贴图**：x 轴 = NdotL，**y 轴 = 部位 ID** |
| 金属高光 | **Matcap**，**直接叠在 albedo 上** |
| 上下渐变 | 用**模型 UV 通道**，不用模型空间 Y |
| 边缘光 | 菲涅尔 / **深度 Sobel** / **ShaderModelID 卷积** |
| 区域标记 | 一张 **ShaderModelID 贴图** |

### ⭐ 今天最值钱的一条

> **上下渐变为什么不能用模型空间 Y？**
>
> **因为角色播放动作时 Y 会翻转**（比如跳水动作头朝下），渐变会跟着反。
> 所以要存到**跟骨骼无关的 UV 通道**里。

**这条的价值不在于"我知道这个技巧"，而在于它体现了一种思维方式：**
**要考虑"动画播放起来之后会怎样"，而不只是"静止状态下对不对"。**
