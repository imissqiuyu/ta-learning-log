---

## 为什么要记这个

学完之后要复盘。但人的记忆会骗人 ——

- 只记得「最后做成了」，忘了中间卡了多久
- 只记得「某个概念我懂」，忘了自己当初是怎么懂的
- 犯过的错**不记下来，下次还会犯**

**所以这份日志的原则是：**

```
✅ 记具体动作，不记"学习了XX"这种空话
✅ 记卡住的过程，不只记结果
✅ 记错误 —— 尤其是 AI 犯的错（这些最有参考价值）
✅ 记提过的问题 —— 问题暴露的就是知识盲区
❌ 不美化、不省略、不"事后诸葛亮"
```

## 关于这份日志的更新方式

**每次和 AI 对话之后，由 AI 自动整理并追加。**

不是我自己手写的 —— 所以它记录的是**真实的对话过程**，
包括我提出什么问题、AI 当时怎么答、后来发现哪里答错了。

> ⚠️ 这意味着日志里会保留一些**当时看起来对、后来被推翻的结论**。
> 这是故意的 —— **学习过程本来就是这样，事后清理掉反而看不出是怎么进步的。**
